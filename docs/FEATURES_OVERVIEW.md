# Momentum 功能概览

Momentum 是一款基于 CTDP（链式时间延迟协议）理论的专注力与自控力训练应用。

## 核心理念

### CTDP 理论基础

- **神圣座位原则**：特定触发器启动任务（如"戴上降噪耳机"）
- **先例原则**：失败的行动要么打断链条，要么成为永久例外
- **线性时间延迟原则**：带辅助链的调度系统

## 详细功能说明

### 1. 任务链系统 (Chains)

**核心功能**：

- 创建带触发条件和时长的任务链
- 8 种链条类型：unit、assault、recon、command、special_ops、engineering、quartermaster、group
- 连续完成次数追踪（当前连击、辅助连击、总完成/失败次数）
- 支持父子关系（层级链条）
- 无时长任务（手动完成）

**用户操作**：

- 创建新链条
- 编辑链条属性
- 复制现有链条
- 查看链条详情和统计
- 删除链条（软删除到回收箱）

### 2. 今日计划 (Daily Plans)

**核心功能**：

- 每个自然日一个计划，不能预建未来日期
- 一个任务链可在当天重复分配为多个独立单元
- 任意顺序启动未完成单元，开始前确认
- 分别显示未完成与已完成单元；完成项按实际完成时间排序
- 周期性与目标性任务链；目标归档前检查当天未完成单元

### 3. 会话管理系统 (Sessions)

**核心功能**：

- 带辅助信号的预约会话
- 活动会话追踪（暂停/恢复）
- 无时长任务的正向计时器
- 可在计时继续运行时返回工作台；活动会话条提供实时状态和暂停/恢复
- 计时任务的关键计时配置和删除操作受到保护，其他任务仍可编辑
- 启动时自动跳过并清理无效或已结束的残留会话，避免错误锁定编辑器
- 会话完成历史
- 与赌注和宠物系统集成

**用户操作**：

- 预约任务（设置辅助信号）
- 开始/暂停/恢复任务
- 完成或中断任务
- 查看任务完成历史

### 4. 任务组系统 (Groups)

**核心功能**：

- 层级任务组，包含子单元
- 时间限制执行（小时）
- 顺序任务执行，自动推进
- 每任务重复次数
- 导入单元（复制或移动模式）

**用户操作**：

- 创建任务组
- 导入单元到组
- 设置时间限制和重复次数
- 顺序执行组
- 重新排序组内任务

### 5. RSIP 系统 (递归稳态迭代协议)

**核心功能**：

- 两种模式：自由模式（每日无限规则）和严格模式（每日最多1条）
- 层级规则树结构
- 稳定阶段：E0（新建）→ E1（稳定，7天）→ E2（内化，21天）
- 执行追踪和违规记录
- 违规时栈删除（删除节点及所有后代）
- 国策组与容错机制
- 强化等级与被动国策标记
- 轮次历史记录（崩溃原因追溯）
- 国策库（归档与恢复已验证国策）
- 分析与推荐引擎（KPI、趋势、风险识别、改进建议）
- RSIP-任务流程双向联动（事件驱动自动化协同）

**用户操作**：

- 添加新规则/政策
- 标记规则为已执行或违规
- 查看带阶段指示器的规则树
- 追踪执行历史
- 切换自由/严格模式
- 查看轮次历史和崩溃原因
- 从国策库恢复已归档国策
- 查看 Insights 面板（KPI、趋势、推荐）
- 配置 RSIP-任务联动（在 RSIP 主界面或任务编辑器内）

### 6. 例外规则系统 (Exception Rules)

**核心功能**：

- 两种规则类型：仅暂停、仅提前完成
- 全局和链条特定范围
- 使用追踪和统计
- 暂停选项：15分钟、30分钟、60分钟或无限制
- 自动恢复功能

**用户操作**：

- 创建暂停/提前完成规则
- 在任务执行期间应用规则
- 查看规则使用统计
- 归档/删除规则

### 7. 赌注系统 (Betting)

**核心功能**：

- 1:1 赔率（赢 = 2倍回报）
- 每会话单次下注
- 每日下注限额和单次最大下注
- 下注历史追踪
- 胜率统计

**用户操作**：

- 开启/关闭赌博模式
- 任务开始前下注
- 查看下注历史
- 检查当前积分和统计
- 设置每日限额

### 8. 电子宠物系统 (Pet)

**核心功能**：

- 宠物属性：饥饿、快乐、健康（0-100）
- 6 个进化阶段：蛋 → 婴儿 → 儿童 → 青少年 → 成年 → 老年
- 等级系统（1-100），指数级经验需求
- 基于属性的心情计算
- 属性随时间衰减
- 任务完成奖励

**用户操作**：

- 创建/领养宠物
- 喂养宠物
- 查看宠物状态和心情
- 追踪宠物进化
- 移动宠物小部件

### 9. 每日签到系统 (Daily Checkin)

**核心功能**：

- 每日签到获取积分奖励
- 连续签到追踪（当前和最长）
- 签到历史
- 今日签到状态

**用户操作**：

- 每日签到
- 查看当前积分
- 查看连续签到信息

### 10. 回收箱系统 (Recycle Bin)

**核心功能**：

- 带时间戳的软删除
- 恢复已删除链条
- 永久删除选项

**用户操作**：

- 查看已删除链条
- 恢复链条
- 永久删除链条

### 11. 导入导出系统 (Import/Export)

**核心功能**：

- 导出所有数据（链条、RSIP节点、设置）
- 从 JSON 导入数据
- 冲突解决
- 批量操作

**用户操作**：

- 导出项目数据
- 从文件导入数据
- 备份和恢复
