# CTDP App 未来改动备忘录

用于记录尚未排期、未来可能实施的产品改动。

## 待办改动

### 保存自定义触发动作，供未来选择

- **目标**：允许用户保存自行配置的触发动作，并在后续创建或编辑相关规则时从已保存的动作中直接选择。
- **状态**：待评估 / 未排期。
- **待明确事项**：保存范围（本地或云端）、动作的命名与编辑方式、删除后对已引用规则的处理，以及导入导出兼容性。

### 为国策增加升级功能

- **目标**：支持对现有国策进行升级，形成明确的成长或强化路径。
- **状态**：待评估 / 未排期。
- **待明确事项**：升级条件与成本、升级等级及效果、是否可回退，以及与现有国策库和执行记录的兼容方式。

### 允许已创建的国策组改名

- **目标**：允许用户修改已经创建的国策组名称。
- **状态**：待评估 / 未排期。
- **待明确事项**：改名入口与权限、名称唯一性和长度限制，以及改名后历史记录、关联国策和导入导出的显示方式。

### 每日签到每天仅限一次

- **目标**：调整每日签到规则，使每位用户在自然日内只能完成一次签到。
- **状态**：已完成（提交 `bcbe767`，2026-08-31）。
- **实现说明**：数据库以 `user_id` 与 `checkin_date` 的唯一约束阻止重复签到；签到业务日固定为纽约时间 08:00 至次日 07:59，重复签到会返回“Already checked in today”。

### 日历支持切换多日视图

- **目标**：在日历表中增加可切换的多日显示模式，便于连续查看和规划日程。
- **状态**：已完成（提交 `bcbe767`，2026-08-31）。
- **实现说明**：完成时间表支持日期选择，以及前一天和后一天切换；切换后展示所选日期的完成记录。

### 修复离开专注页后任务完成无提示音

- **问题**：开始任务后离开专注页，任务完成时没有播放提示音。
- **状态**：待修复 / 未排期。
- **待明确事项**：提示音应由会话完成事件统一触发，还是由专注页之外的全局通知层触发；同时确认后台标签页、静音设置与重复播放的处理方式。

### 修复创建国策后每日完成记录板块消失

- **问题**：创建一个国策之后，原有的“每日是否完成国策”记录板块消失。
- **状态**：待修复 / 未排期。
- **待明确事项**：确认板块消失的触发条件、国策创建前后的数据关联，以及已有每日完成记录的保留与恢复方式。

### 修复计时期间可开启其他任务

- **问题**：一项任务正在计时时，仍可开启其他任务，导致同时存在多个活动任务或计时会话。
- **目标**：开启任务计时后，阻止用户再启动其他任务，直到当前任务完成、中断或明确结束。
- **状态**：待修复 / 未排期。
- **待明确事项**：启动入口的统一拦截位置、按钮禁用与提示文案，以及异常恢复或残留会话场景下的处理方式。
