# CTDP App 未来改动备忘录

用于记录尚未排期、未来可能实施的产品改动。

## 待办改动

### 保存自定义触发动作，供未来选择

- **目标**：允许用户保存自行配置的触发动作，并在后续创建或编辑相关规则时从已保存的动作中直接选择。
- **状态**：待评估 / 未排期。
- **待明确事项**：保存范围（本地或云端）、动作的命名与编辑方式、删除后对已引用规则的处理，以及导入导出兼容性。

### 为国策增加升级功能

- **目标**：支持对现有国策进行升级，形成明确的成长或强化路径。
- **状态**：待评估 / 未排期。
- **待明确事项**：升级条件与成本、升级等级及效果、是否可回退，以及与现有国策库和执行记录的兼容方式。

### 每日签到每天仅限一次

- **目标**：调整每日签到规则，使每位用户在自然日内只能完成一次签到。
- **状态**：待评估 / 未排期。
- **待明确事项**：时区与“自然日”的定义、重复签到时的提示方式，以及历史重复签到数据的处理策略。

### 日历支持切换多日视图

- **目标**：在日历表中增加可切换的多日显示模式，便于连续查看和规划日程。
- **状态**：待评估 / 未排期。
- **待明确事项**：支持的视图范围（如 3 日、周或月）、切换入口与默认视图，以及不同屏幕尺寸下的布局策略。
